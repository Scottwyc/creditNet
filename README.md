# CreditNet SOC Project

本仓库用于跟踪信贷网络自组织临界性实验的核心代码、核心报告和可复现的关键结果摘要。

## 主要内容

- `project.md`：当前模型框架、算法流程和实验设计的主文档。
- `src/creditnet/`：信贷网络仿真核心实现。
- `scripts/`：实验运行、统计检验、图表与报告生成脚本。
- `docs/`：阶段报告、综合报告、Word 导出版本和结果仪表盘。
- `results/`：仅跟踪筛选后的核心证据文件，包括摘要表、元数据、关键图表和分析报告。

## 结果跟踪口径

`results/` 下的逐事件原始数据、逐期历史、临时渲染目录和大体量扫描输出默认不纳入 Git，例如 `avalanche_events.csv`、`avalanche_waves.csv` 和 `first_run_*histories.json`。这些文件仍保留在本地磁盘，用于必要时复算或审计。

需要进入 Git 的结果文件应满足至少一项条件：

- 是报告中直接引用的图表、摘要表或证据门槛结果；
- 是复现实验配置、元数据或 manifest；
- 是最终 SOC 判定所依赖的版本化分析产物。

如后续需要完整版本化原始事件流，建议单独启用 Git LFS 或建立外部数据归档，而不是直接放入普通 Git 历史。
