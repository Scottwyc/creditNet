# 信贷网络自组织临界实验协议

更新时间：2026-06-02 00:00:00 CST

## 目标

基于 `project.md` 的个体信贷网络设定，构造可复现实验框架，观察初始本金分布、收入分配方式和网络增长机制如何影响：

- 首次级联违约前的信贷规模；
- 级联违约规模分布；
- 大崩塌事件频率；
- 崩塌规模和频率之间是否存在幂律型尾部。

## 2026-06-04 当前主实验协议修订

当前主实验已从第一版“首次违约即停止”升级为：

- 每个 `time_step` 只新增 1 个单位信贷；
- 一个 `period` 包含多个 `time_step`；
- 只在 `period_end` 结算支出、分配收入、检查违约和完成级联；
- 主分析使用 `continue_after_avalanche`，即一次级联完成后继续下一期并记录长期 avalanche 序列；
- 每个 avalanche 单独记录到 `avalanche_events.csv`；
- `stop_on_first_default` 仅作为首次崩塌临界信贷规模对照协议保留。

## 第一版模型口径

节点表示个体，状态包括：

- `cash`：货币现金；
- `loan_assets`：对其他个体的贷款资产；
- `debt_liabilities`：从其他个体借入形成的债务；
- `net_worth = cash + loan_assets - debt_liabilities`。

信贷边为 `lender -> borrower`，每次新增 1 单位信贷。新增信贷时：

- 贷款人现金减少 1，贷款资产增加 1；
- 借款人现金增加 1，债务负债增加 1；
- 借贷本身不改变双方净资产。

## 流量机制

收入内生协议中，每期计划信贷 time_step 数量为：

```text
K_t = planned_credit_steps = round(c * previous_total_income)
```

其中 `c` 是无量纲的投资/信贷驱动比例，第一版默认 `c = 0.20`。它把上一期总收入转换成下一期计划执行的单位信贷 time_step 数量，不改变单笔信贷的 1 单位规模。`c` 越大，两次 `period_end` 违约检查之间计划累积的信贷尝试越多。

初始上一期收入用 `initial_income_per_capita` 引导，避免第 1 期信贷增长为 0。它只作为第一期消费和 `K_1` 的参考量，不向系统注入现金。当前常用 `N=200`、`initial_income_per_capita=5`，所以 `Y_0=1000`，在 `c=0.20` 时第一期计划执行 `K_1=200` 个 time_step。

固定 `K` 对照实验直接令每期 `K_t=K`。此时元数据中的 `c` 不参与模拟。

支出分两部分：

- 投资支出：当期成功借入资金作为当期投资支出目标；实际支出受现金约束，如果借款人在期内又将现金贷出，实际投资支出可能小于借入量；
- 消费支出：`a * max(net_worth, 0) + b * last_income`，经过随机舍入并受现金余额约束。

当前实现先支付投资支出，再以剩余现金支付消费支出。总收入严格等于实际总支出。收入分配规则：

- `uniform`：每单位收入等概率分配给任一主体；
- `biased`：按 `max(net_worth, 0) + floor` 的权重偏好分配，当前 `floor=1`。

每单位收入通过多项分布分配。支出形成的同额收入重新加入现金，因此系统总现金守恒。

## 级联违约机制

违约条件：

```text
net_worth < 0
```

本版级联机制采用信用风险传播口径：

1. 债务人违约后，其未偿债务对应的债权人贷款资产减记；
2. 债权人净资产因此下降；
3. 若债权人净资产转负，则继续触发违约；
4. 直到不再产生新违约为止。

第一版对照协议在首次出现违约并完成级联后停止。当前主实验使用长期 `continue_after_avalanche` 协议，完成级联后继续下一期。

当前 `wipe_defaulted_assets=True`：违约节点作为债权人持有的贷款资产也会被清除，对应借款人的负债同步解除。级联过程不直接扣减现金。违约节点在清算后不会永久退出，后续 period 仍可重新参与系统。

## 第一批实验变量

- 初始本金分布：`equal / uniform / normal / lognormal / pareto`
- 收入分配机制：`uniform / biased`
- 网络增长机制：
  - `random`：随机贷款人、随机借款人；
  - `borrower_preferential`：随机贷款人，借款人按正净资产偏好选择；
  - `preferential`：贷款人按现金偏好选择，借款人按正净资产偏好选择；
  - `borrower_debt_preferential`：随机贷款人，借款人按既有债务规模偏好选择；
  - `preferential_debt`：贷款人按现金偏好选择，借款人按既有债务规模偏好选择。

## 结果口径

每个 run 记录：

- `time_steps_completed`：累计实际执行的信贷尝试步数，不一定等于成功发放量；
- `total_credit_issued`：累计成功发放的单位信贷量；
- `credit_scale_before_cascade`：级联前仍活跃的信贷暴露总量，不是唯一连边数或累计发放量；
- `collapse_size`：事件表中为本次级联违约节点数，run 汇总表中为该 run 的最大级联规模；
- `collapse_fraction`：级联规模占节点比例；
- `critical_event`：事件表中表示该次级联是否达到阈值，run 汇总表中表示该 run 是否至少发生过一次大级联；
- 初始本金 Gini 和最终净资产 Gini。

信贷暴露矩阵是带权矩阵；同一贷款人与借款人之间可以反复增加单位信贷。因此每个成功 time_step 新增的是 1 单位暴露，不保证产生一条新的唯一网络连边。
